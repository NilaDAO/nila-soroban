# Event schema

Generated by `scripts/event-schema.py` from the `#[contractevent]` structs (106 events); do not edit by hand.
Every event is kept by the indexer at [indexer.nila.land](https://indexer.nila.land/events) (nila-sensing `indexer/`), where `name` is the first topic and `contract` the deployed name below.

**Shape (soroban-sdk default):** topics = `[name, …the topic fields in order]`; data = a map of the data fields.
Amounts (`i128`) are in the asset's units, 7 decimals (`docs/STORAGE_AND_DECIMALS.md`).

## nin_sac (the nIN token)

The Stellar Asset Contract of nIN: Stellar's standard token events (CAP-46-6, SEP-41), not Nila code. Seen on mainnet: `mint`, `transfer`, `set_admin`, `set_authorized`; also possible: `burn`, `clawback`, `approve`. Topics `[name, from/admin, to, "nIN:<issuer>"]`, data the amount (i128).
